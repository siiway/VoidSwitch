# 身份组

**身份组**决定了其成员可以调用哪些[模型](/admin/models)。
**身份组**页面是**仅限管理人员**的。

## 成员资格如何运作

成员资格在**登录时根据用户的 Prism 团队角色自动分配**。
一个组定义一个或多个**映射**，每个映射格式为：

> 团队 `T` 中有效角色至少为 `R` 的成员获得此组。

角色排序为 `owner > co-owner > admin > member`。自动成员资格在每次登录时重新计算；
如果在映射仍然匹配的情况下进行临时手动移除，将在下次登录时重新授予。

## 创建组

1. 打开**身份组** → **添加**。
2. 为其命名并添加可选描述。
3. 添加**映射**：团队 ID 和最低角色。
4. 保存。然后在[模型](/admin/models)页面上，将此组列在它应解锁的模型下。

## 调用限流

每个身份组都有自己的**调用限流**：其成员在 OpenAI / Anthropic 网关端点
（`/v1/chat/completions`、`/v1/messages`）上"N 秒内最多 X 个请求"。
新建的组默认 30 秒内最多 30 个请求；最大请求数设为 `0` 表示该组不限流。
限流仍**按用户计数**：一个成员加入多个身份组时，只要其中任一组（且该组有权调用
相应模型）还有额度，就可以继续调用。

在组的编辑对话框中修改限流。内置 **moderator** 组不能重命名、不能修改映射，
但可以调整它的限流（默认 30 秒内最多 50 个请求）。

::: tip
控制台管理操作（添加/编辑/删除/保存）的限流是固定的（20 秒内最多 30 个请求），
不在此处配置。
:::

## 内置 moderator 组

**moderator** 组在首次启动时创建，始终授予对所有模型的访问权限，不可重命名或删除
（但其调用限流可以调整）。
Owner / co-owner / admin 隐式属于它 — 这就是为什么管理人员始终可以调用任何模型。

## 紧急移除访问权限

从组的**成员**视图中，你可以临时移除用户，以立即切断其对该组模型的访问权限
（适用于无法立即禁用账户的情况）。如果映射仍然匹配，将在下次登录时重新授予 —
要使其永久生效，请移除映射或禁用账户。
