# 模型（管理）

**模型**页面对所有人可见，但管理人员可以管理它。参见
[用户版模型指南](/guide/models)了解读者视角。

## 每个模型的元数据

对于任何模型 ID，管理人员可以设置：

- **显示名称**和**描述**；
- **公开别名**（`mapped_id`） — 设置后，客户端看到并必须使用此 ID 而非原始上游 ID，
  隐藏上游并消除歧义冲突；
- 自定义**OpenCode 配置**，插件会将其深度合并到该模型中；
- **启用** — 将模型从 `/v1/models` 和选择器中隐藏，而不删除它；
- 允许调用它的**身份组**。

## 批量编辑

同时将相同的更改应用到多个模型 — 描述、启用状态、允许的身份组或 OpenCode 配置。
可以先使用搜索、提供商、可用状态或身份组筛选，再勾选**选择当前筛选结果**。清除筛选后，已选择的模型会保持选中；需要重新开始时点击**清除选择**。
对于 OpenCode 配置，选择：

- **合并** — 深度合并到每个模型的现有配置中（嵌套字典合并，列表/标量替换）；或
- **覆盖** — 完全替换。

## 访问控制

- 内置的 **moderator** 组（owner/co-owner/admin）始终可以调用所有模型。
- 其他用户需要模型列出的[身份组](/admin/role-groups)。
- 因此，空的允许列表意味着"仅限 moderator"。

## 同步与清理

这里有**两个相互独立**的"同步"：

- **从供应商同步**（模型页面的按钮，`POST /api/models/sync`）为已启用供应商当前
  服务的所有模型 ID 添加目录行，**重塑共享目录**。这是**仅限管理人员**的操作，
  成员看不到该按钮。
- **OpenCode 同步**（`POST /v1/models/sync`，即 OpenCode 的 `/sync-models` 命令）
  面向**所有成员**开放。它*不会*重塑共享目录，只是回报该令牌**当前可调用**的模型
  集合（应用身份组访问与令牌允许列表、排除隐藏/禁用模型），供插件把自己的模型列表
  与用户实际拥有的权限对齐。因此成员无需管理员权限即可同步。
- **清理未服务的**删除没有供应商再服务的模型元数据行（仅限管理人员）。

## 隐藏模型

取消勾选**可用**会隐藏模型（对管理人员显示"不可用（已隐藏）"徽章）。
成员永远看不到隐藏模型 — 不在模型页面、`/v1/models` 或 OpenCode 选择器中。
