# 模型（管理）

**模型**页面对所有人可见，但管理人员可以管理它。参见
[用户版模型指南](/guide/models)了解读者视角。

## 暴露模型

**模型**页面列出**暴露模型**（例如 `fast-coder`、`astr-chat`）—— 这是用户 / 客户端
**唯一**会看到的 ID。上游模型 ID（例如 `deepseek/deepseek-chat`）永远不会对外暴露。

每个暴露模型有一个**路由流程图**：

- 顶部是**暴露模型本身**；
- 下面是按顺序排列的**层**（层 = 回退池）；
- 每一层是一个**池**，包含若干上游条目（供应商 + 上游模型 + 权重），并带一个**每层
  最大尝试次数**（`max_attempts`；`1` = 只挑一个，`>1` = 尝试多个）。

可回退的失败（429 限流 / 404 模型不存在 / 5xx）会向下游流程或下一个上游移动；
**400**（客户端错误）按原样返回；明确判定为**配额耗尽**的响应会禁用该上游密钥。

路由流程图在**专门的页面**上编辑：顶层模型 → 层池 → 上游。

## 每条暴露模型的元数据

对于任何暴露模型，管理人员可以设置：

- **显示名称**和**描述**；
- 结构化字段 **limit_context / limit_input / limit_output / reasoning /
  capabilities（text/image/audio/tool）/ modalities**；
- 自定义 **OpenCode 配置**（`opencode_config`）；
- **启用** — 将模型从 `/v1/models` 和选择器中隐藏，而不删除它；
- 允许调用它的**身份组**。

### models.dev 集成

- 在**模型**页面搜索 **models.dev**，把某个模型**映射**到暴露模型；
- 它的数据会作为**占位元数据**使用（你填写的内容会覆盖它）；
- 同步间隔由设置 `models_dev_sync_interval_minutes` 控制（默认 `1440` = 每天）；
- 端点：`/api/models/models-dev/search?q=`、`/api/models/models-dev/sync`。

### 下游配置优先级（OpenCode 插件）

结构化字段 **>** 自定义 `opencode_config` **>** models.dev 占位 **>** 默认值。

## 批量编辑

同时将相同的更改应用到多个模型 — 描述、启用状态、允许的身份组或 OpenCode 配置。
可以先使用搜索、提供商、可用状态或身份组筛选，再勾选**选择当前筛选结果**。清除筛选后，已选择的模型会保持选中；需要重新开始时点击**清除选择**。
对于 OpenCode 配置，选择：

- **合并** — 深度合并到每个模型的现有配置中（嵌套字典合并，列表/标量替换）；或
- **覆盖** — 完全替换。

## 访问控制

- 内置的 **moderator** 组（owner/co-owner/admin）始终可以调用所有模型。
- 其他用户需要模型列出的[身份组](/admin/role-groups)。
- 因此，空的允许列表意味着"仅限 moderator"。

## 从供应商同步

**从供应商同步**（模型页面的按钮，`POST /api/models/sync`）摄取已启用供应商当前服务的
上游模型，并**重塑共享目录**。这是**仅限管理人员**的操作，成员看不到该按钮。
（OpenCode 的 `/sync-models` 命令 —— `POST /v1/models/sync` —— 面向**所有成员**开放，
用于把插件列表与你**当前可调用**的暴露模型对齐，从不改动共享目录。）

**清理未服务的**删除不再有上游模型服务的元数据行（仅限管理人员）。

## 隐藏模型

取消勾选**可用**会隐藏模型（对管理人员显示"不可用（已隐藏）"徽章）。
成员永远看不到隐藏模型 — 不在模型页面、`/v1/models` 或 OpenCode 选择器中。
