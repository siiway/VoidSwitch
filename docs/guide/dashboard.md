# 控制台概览

登录后你将进入**控制台** — 你的主页。显示的内容取决于你的层级。

## 所有人可见

- **公告** — 最新的平台公告。参见[公告](/guide/announcements)。
- 侧边栏中的**文档**选项卡（账户部分）在新标签页中打开此文档。

## 成员可见

控制台汇总**你自己**的活动：

- **我的请求** — 你通过网关发出的请求数量。
- **我的令牌用量** — 你的请求消耗的总令牌数。
- **我的 API 密钥** — 你当前持有的 Void-Token 数量。

成员看不到平台范围统计或供应商页面。

## 活跃度热力图

页面**底部**是一张类似代码托管站「贡献图」的**活跃度热力图**，按天展示你的 Token 用量（颜色越深当天用得越多；悬停某一格可看到该日的**精确** Token 数，不做「万 / 亿」缩写）。热力图上方还有几项汇总：

- **累计 Token 数** — 保留窗口内的总用量。
- **峰值 Token 数** — 单日最高用量。
- **最长任务时长** — 依据会话 ID 计算的单个会话（任务）从首次到最后一次请求的最长跨度。
- **当前连续天数 / 最长连续天数** — 连续有用量的天数。

管理人员的控制台会**同时**显示两张热力图：**站点活跃度**（全站汇总）和**我的活跃度**（本人数据）。

## 管理人员可见

管理人员看到平台范围的概况：

- **供应商**、**活跃密钥**、**Void-Token** 数量。
- **24 小时活动**：请求数、成功数、失败数、成功率、Token 使用量、平均首字时间（TTFT）、平均 Token/请求和 **Token 吞吐（tok/s，= 总 Token / 总请求耗时）**。
- **后台任务**：余额探测、代理复活和日志清理定时任务的状态。
- 页面底部的**站点**与**个人**活跃度热力图（见上文「活跃度热力图」）。

## 模型与节点健康

原来的独立**健康**页面已并入**模型**和**节点**页面：

- **模型页**的每张卡片仍显示健康摘要行（状态、近期成功率、平均首字时间、吞吐与样本数）；点击卡片可打开**模型详情弹窗**，查看完整描述、能力、限制、健康摘要，以及（仅管理人员）每个上游候选的成功率 / 首字时间 / 样本数与冷却状态。成员看不到上游信息。
- **节点页**的节点表新增**排序分数**与**探测趋势**两列，并可在表头上方切换健康窗口（30m / 1h / 3h / 12h / 1d / 3d / 7d）。

## 侧边栏导航

侧边栏将页面分为**概览**、**路由**、**运维**和**账户**。你只会看到你的层级可以访问的页面；主题切换、语言切换和退出登录位于页脚。

侧边栏在桌面端可以**收起为图标栏**（页脚右下角的箭头按钮，状态会记在浏览器本地）。收起后鼠标移到**页面最左边缘**会临时滑出完整侧边栏（覆盖在内容之上，不挤压页面），移开即收起；窄屏（≤768px）仍使用汉堡按钮的抽屉式侧栏。将鼠标悬停在侧栏顶部的标语上还会显示当前构建版本。

| 页面 | 谁可见 |
| ---- | ---- |
| 控制台 | 所有人 |
| 模型、统计、日志 | 所有人 |
| 聊天、我的令牌、文档 | 所有人 |
| 供应商、代理、用户、身份组、设置 | 管理人员 |
| 令牌 | 所有者 |
