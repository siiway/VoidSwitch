# 模型目录

**模型**页面列出了平台中所有可用的模型 ID，每个模型一张卡片。所有已登录用户均可查看。

## 卡片显示的内容

- 你调用时使用的**公开 ID**（可能是上游 ID 的别名）。
- 管理人员设置的可选**显示名称**和**描述**。
- 当前哪些**供应商**提供服务，以及是否**正在服务**。
- 你是否**被允许**调用它（基于你的身份组）。

## 搜索与筛选

顶部工具栏可按关键字搜索（可选择匹配字段），并按**供应商**和**可用性**筛选。
按**身份组**筛选是管理人员专属的，成员不会看到该筛选项。

## 我可以调用哪些模型？

- **管理人员**（owner / co-owner / admin）可以调用所有模型。
- **成员**可以调用模型，如果其某个[身份组](/admin/role-groups)被允许访问该模型。成员资格在登录时根据你的团队角色自动分配。

如果你期望的模型缺失，可能是因为当前没有启用的供应商提供服务，你的身份组可能未授予访问权限，
或者它可能被管理人员**隐藏**（禁用）了 — 隐藏的模型完全不向成员显示。如果你认为某个模型应该可用，请询问管理员。

## 刷新目录

**重塑共享目录**（为新服务的模型 ID 注册目录行）是**仅限管理人员**的操作
（admin / co-owner / owner），通过**模型**页面上的**从供应商同步**按钮
（`POST /api/models/sync`）完成。成员看不到该按钮。

**OpenCode 用户（含成员）**则用 `/sync-models` 命令（`POST /v1/models/sync`）
让插件把模型列表与自己**当前可调用**的模型对齐 —— 这一步对所有成员开放、无需管理员
权限，也不会改动共享目录。你只会看到自己有权访问且未被隐藏的模型。

成员通常无需刻意同步 —— 已服务且你有权访问的模型已出现在列表和 `/v1/models` 中。

## 调用模型

使用模型的**公开 ID** 作为请求中的 `model` 字段。参见[调用 API](/guide/using-the-api)。
